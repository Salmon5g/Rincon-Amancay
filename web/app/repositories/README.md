Consultas autorizadas de Firestore para la web. Las operaciones que modifican cuentas se envían a la API autenticada; las páginas no escriben directamente en Firestore.

- `admin.ts`: lecturas del panel y catálogos. `listarCatalogosAdmin` exige sesión administrativa, lee estados activos e inactivos y carga la versión vigente de los tipos de producto. `crearValorCatalogo`, `editarValorCatalogo` y `cambiarEstadoValorCatalogo` llaman a la API autenticada; el repositorio nunca escribe directamente en Firestore. El listado de sectores para invitaciones mantiene la consulta pública de valores activos.
