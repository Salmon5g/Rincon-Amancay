Consultas autorizadas de Firestore para la web. Las operaciones que modifican cuentas se envían a la API autenticada; las páginas no escriben directamente en Firestore.

- `admin.ts`: lecturas y operaciones del panel. Los métodos de catálogos, asociaciones, ferias, preferencias de acceso y cuentas administradoras llaman a la API autenticada; el repositorio nunca escribe directamente en Firestore para esos módulos. `listarCatalogosAdmin` exige sesión administrativa, lee estados activos e inactivos y carga la versión vigente de los tipos de producto. El listado de sectores para invitaciones mantiene la consulta pública de valores activos.
